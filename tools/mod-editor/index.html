CTPS5 mod editor

Open this file in your browser. Everything runs locally. Choose PNGs and download a ready-to-copy mod ZIP. Missing images use the original game assets. Host 01.006.012 or later is required.

Portrait HUD theme


Drop a PNG here to assign it to the selected role.
    Preview uses example stats. Unreplaced portraits are labelled placeholders here; the game uses its original portraits. The native game renderer supplies final text and positioning.
    Advanced layout, labels, colours and asset paths (JSON)

    Edit this generated JSON directly. Positions are relative to each of the three party cards. Keep asset paths inside the theme folder.

    Copy the ZIP's eggoftime folder into /data/. Select the theme in L3+R3 → Mods → HUD theme. Press A there to reload edited PNGs and JSON.

    Other dumped graphics

    Choose a folder containing your edited dump files. Keep the original folders and names: frames/Chara/Chara_0000/000.png replaces Crono's stored pose 000. A loose 000.png cannot identify a character.

    Use a name such as cronos-house-downstairs for a separate On/Off switch in host 01.006.018 or later. Leave blank to use the Default folder. This packages already edited dump-layout PNGs; it cannot turn a whole room illustration into game tiles.
      The editor preserves each PNG's bytes and relative path and generates an inventory JSON. JSON is optional for loading graphics. Install only edited PNGs; copying the whole dump overrides every included graphic. Restart CTPS5 after changing these graphics. Fonts retain their original size; other sprite/background PNGs must retain the original canvas or use a whole-number scale from 1× to 8×.
